# OPIc Coach 🎙️

OPIc **IM3 · IH · AL** 취득을 위한 모바일 스피킹 트레이너.
설치형 웹앱(PWA)이라 앱스토어 없이 폰 홈 화면에 설치되고, 오프라인에서도 동작하며, 모든 학습 자료는 이 저장소의 JSON 파일이라 **GitHub 모바일 앱에서 바로 수정**할 수 있습니다.

## 무엇을 할 수 있나

| 기능 | 설명 |
|---|---|
| 📚 주제별 학습 | 설문 12주제 + 롤플레이 + 돌발 + 고난도. 주제당 표현 15개, 질문 4~8개, 각 질문에 **IM3 / IH / AL 모범답안** |
| 🔊 듣기·섀도잉 | 브라우저 TTS로 표현·모범답안을 문장 단위 재생(느리게 가능), 따라 말하면 음성 인식으로 일치율 확인 |

| 🔁 간격 반복 | 표현 카드에 "알아요/몰라요" → Leitner 5단계 복습 스케줄 |

## 바로 시작하기

안드로이드 설치(APK 필요 여부 포함)는 [ANDROID.md](ANDROID.md) 참고.

1. **GitHub Pages 주소**를 폰 브라우저(Android Chrome / iPhone Safari)로 엽니다.
2. 홈 화면에 추가: Android는 메뉴 → **앱 설치**, iPhone은 공유 → **홈 화면에 추가**.
3. 설정(⚙️)에서 **목표 등급 · 시험일**을 입력하고 **"시험일에 맞춰 자동 설정"**을 누릅니다.
   시험일을 비워 두면 홈 D-day가 **가장 빠른 응시 가능일**(일요일·공휴일 제외)을 자동으로 사용하고, 등록한 시험일이 지나도 다음 날짜로 넘어갑니다.
4. 홈의 **오늘의 학습**을 순서대로 진행합니다. 첫날 **미니 모의고사**로 현재 레벨을 확인하세요.

> 음성 인식(STT)은 **Android Chrome**에서 가장 잘 동작합니다. iPhone Safari도 지원하지만 녹음과 동시에 인식이 안 될 수 있습니다. 인식이 안 되는 브라우저에서는 녹음을 듣고 자가 평가할 수 있습니다.

## 추천 학습 루틴 (하루 45~60분)

1. 발음 5분 – 오늘의 소리 세트 (최소대립쌍 퀴즈 + 문장 따라 말하기)
2. 패턴 8분 – 카드 모드로 한 그룹
3. 주제 표현 15분 – 카드 모드로 15개, 뜻 안 보고 말할 수 있을 때까지
4. 섀도잉 15분 – 목표 레벨 모범답안 문장별로 듣고 따라 말하기 → 가리기 모드로 재현
5. 직접 답변 15분 – 같은 질문에 녹음 → 채점 → 피드백 반영해 한 번 더
6. 주 1회 – 미니 모의고사, 격주 – 실전 모의고사

## 콘텐츠 수정 (폰에서도 가능)

앱 안의 ✏️ 버튼이 해당 JSON 파일의 GitHub 편집 화면으로 바로 연결됩니다. 자세한 형식은 [CONTENT_GUIDE.md](CONTENT_GUIDE.md) 참고.
잘못된 JSON을 저장하면 GitHub Actions가 실패 표시를 해주고, 앱은 마지막으로 정상이던 파일을 계속 사용합니다.

## 로컬에서 실행

```bash
python -m http.server 8765
```

브라우저에서 `http://localhost:8765` 접속. (`file://` 로는 모듈·서비스워커가 동작하지 않습니다.)

## 배포

GitHub → Settings → Pages → Source: **Deploy from a branch**, Branch: `main` / `/ (root)`.
몇 분 후 `https://<계정>.github.io/<저장소>/` 에서 접속할 수 있습니다. `js/config.js` 의 `repo` 값이 저장소와 맞아야 ✏️ 편집 링크가 정확히 열립니다.

## 채점 방식 안내

앱의 점수는 실제 OPIc 채점이 아니라 **학습 방향을 잡기 위한 추정치**입니다. 전사된 답변에서
발화량(30) · 구성/연결어(25) · 문법/시제(15) · 어휘 다양성(15) · 유창성(15) 을 계산해 0~100점으로 만들고,
63점 이상 IM3, 78점 이상 IH, 90점 이상 AL 로 매핑합니다. 발음 자체는 음성 인식 일치율로만 간접 평가합니다.

## 시험 일정 데이터

OPIc은 고정된 시험일 목록이 없는 **상시시험**이라, 홈 D-day는 `data/exam-schedule.json`
의 휴무 규칙(일요일 + 공휴일)으로 **다음 응시 가능일**을 계산합니다. 접수 마감일도
같은 파일의 `registration.closesDaysBefore` 로 구합니다.

- 공휴일은 `.github/workflows/exam-schedule.yml` 이 매달 자동 갱신합니다.
  수동 실행은 `node tools/update-exam-schedule.mjs`.
- 임시공휴일처럼 API에 늦게 반영되는 날은 `holidays` 에 직접 추가해도 됩니다
  (자동 갱신 때 지워지지 않고 유지됩니다).
- `coverageUntil` 이 지나면 앱은 일요일만 제외해 계산하고 홈에 안내를 띄웁니다.
  워크플로도 이슈를 열어 알립니다.
- 날짜 계산 테스트: `node tools/test-exam.mjs`

접수 마감·좌석 정책은 앱 안내가 아니라 [공식 사이트](https://www.opic.or.kr)가 기준입니다.

## 자동 반복 재생 · 화면 유지

버튼을 매번 누르지 않고 듣고 → 따라 말하기를 반복할 수 있습니다.

- **▶ 자동 재생**: 주제 표현 · 주제 발음 · 만능 패턴 · 발음 훈련 목록 상단
- **카드 모드**: 카드를 넘길 때마다 자동 반복
- **섀도잉 ▶ 전체 듣기**: 문장마다 자동 반복
- **반복 횟수**(1·2·3·5회)와 **간격**(0·0.8·1.5·2.5초)은 화면끼리 공유되고 저장됩니다

재생·녹음·모의고사 중에는 [Screen Wake Lock](https://developer.mozilla.org/docs/Web/API/Screen_Wake_Lock_API)
으로 화면이 꺼지지 않습니다. Android Chrome 과 iOS Safari 16.4+ 에서 동작하며,
지원하지 않는 브라우저에서는 자동 재생만 되고 화면 유지는 안내가 표시되지 않습니다.

가로 화면은 `manifest.webmanifest` 의 `orientation: "any"` 와
`@media (orientation: landscape)` 규칙으로 지원합니다.

UI 테스트(자동 재생·화면 유지·가로 화면)는 `tools/test-ui.mjs` 에 있습니다.
저장소를 의존성 없이 유지하려고 CI 에는 넣지 않았으니, 돌려 보려면 파일 맨 위 안내를 따르세요.

## 집중 학습 (최단 코스)

`#/focus` — 주제별 전체 학습은 그대로 두고, **목표 등급까지 필요한 것만** 따로 모은 화면입니다.
설정의 목표 등급(IM3 / IH / AL)에 따라 내용이 바뀝니다.

1. **서베이 추천 조합** — OPIc은 Background Survey에서 고른 항목이 그대로 2~10번 문제로
   나옵니다. 어휘와 스토리가 겹치는 항목만 고르면 같은 답변을 여러 문제에 재활용할 수 있어
   준비량이 줄어듭니다. 고를 항목과 **피할 항목**을 이유와 함께 보여 주고, 체크해 두면
   시험장에서 그대로 고를 수 있게 저장됩니다.
2. **좁힌 주제** — 전체 15개 중 목표 등급에 필요한 것만 (IM3 6개 / IH 10개 / AL 13개)
3. **같이 할 패턴·발음**
4. **달성 조건 체크리스트** — 모의고사 점수보다 먼저 확인할 항목

구성은 `data/focus.json` 에 있습니다. 여기 적힌 주제·패턴·발음 id 는
`tools/validate.py` 가 실제 데이터와 대조해 검사하므로, 오타가 있으면 CI 에서 걸립니다.

서베이 추천은 공개된 학습 전략을 정리한 것이고 합격을 보장하지 않습니다.
실제 서베이 항목과 문항 구성은 [OPIc 공식 사이트](https://www.opic.or.kr)가 기준입니다.

`tools/test-ui.mjs`(자동 재생·화면 유지·가로 화면), `tools/test-focus.mjs`(집중 학습),
`tools/test-mock.mjs`(모의고사 전 과정). 저장소를 의존성 없이 유지하려고 CI 에는 넣지
않았으니, 각 파일 맨 위 안내를 따라 실행하세요.
