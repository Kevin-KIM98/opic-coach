# OPIc Coach 🎙️

OPIc **IM3 · IH · AL** 취득을 위한 모바일 스피킹 트레이너.
설치형 웹앱(PWA)이라 앱스토어 없이 폰 홈 화면에 설치되고, 오프라인에서도 동작하며, 모든 학습 자료는 이 저장소의 JSON 파일이라 **GitHub 모바일 앱에서 바로 수정**할 수 있습니다.

## 바로 시작하기

안드로이드 설치(APK 필요 여부 포함)는 [ANDROID.md](ANDROID.md) 참고.

1. **GitHub Pages 주소**를 폰 브라우저(Android Chrome / iPhone Safari)로 엽니다.
2. 홈 화면에 추가: Android는 메뉴 → **앱 설치**, iPhone은 공유 → **홈 화면에 추가**.
3. 설정(⚙️)에서 **목표 등급 · 시험일**을 입력하고 **"시험일에 맞춰 자동 설정"**을 누릅니다.
   시험일을 비워 두면 홈 D-day가 **가장 빠른 응시 가능일**(일요일·공휴일 제외)을 자동으로 사용하고, 등록한 시험일이 지나도 다음 날짜로 넘어갑니다.
4. 홈의 **오늘의 학습**을 순서대로 진행합니다. 첫날 **미니 모의고사**로 현재 레벨을 확인하세요.

> 음성 인식(STT)은 **Android Chrome**에서 가장 잘 동작하고 **인터넷 연결이 필요합니다**. iPhone Safari도 지원하지만 녹음과 동시에 인식이 안 될 수 있습니다. 인식이 안 될 때는 원인과 해결 방법을 화면에서 안내하고, 답변을 직접 입력해 채점받을 수도 있습니다 → [음성 인식이 안 될 때](#음성-인식이-안-될-때).

## 추천 학습 루틴 (하루 45~60분)

주제 하나를 골라 끝까지:

1. ① 표현 10분 – 카드 모드로 15개, 뜻 안 보고 말할 수 있을 때까지
2. ② 패턴 10분 – 이 주제에 맞춘 만능 패턴 8문장을 말하기 퀴즈로
3. ③ 답안 20분 – 목표 레벨 모범답안 섀도잉 → 🇰🇷→🇺🇸 한글 보고 말하기 → 직접 녹음 · 채점
4. 틈날 때 – 만능 패턴 72문장 전체를 자동 재생으로
5. 주 1회 – 미니 모의고사, 격주 – 실전 모의고사

## 버전 · 업데이트 확인

홈 상단에 **지금 실행 중인 버전과 업데이트 시각**(예: `v4.5.0 · 10월 27일 11:34 업데이트`)이 보입니다.
홈을 열 때마다 서버의 `js/config.js` 를 캐시 없이 읽어 버전이 다르면 **🔄 새 버전 적용** 버튼이 나타나고,
누르면 예전 앱 파일 캐시를 지우고 다시 엽니다. 앱 파일은 매번 서버에 바뀌었는지 확인하므로(바뀌지 않았으면 304)
보통은 다시 열기만 해도 새 버전이 적용됩니다.

버전을 올릴 때는 `js/config.js` 의 `version` · `updated`(한국 시간 `YYYY-MM-DD HH:MM`)와 `sw.js` 의 `VERSION` 을
함께 바꿉니다. `tools/validate.py` 가 둘이 맞는지 검사합니다. 테스트: `tools/test-version.mjs`.

## 콘텐츠 수정 (폰에서도 가능)

**편집자 모드**(설정 맨 아래 버전 표시를 7번 탭)를 켜면 ✏️ 버튼이 나타나, 해당 JSON 파일의 GitHub 편집 화면으로 바로 연결됩니다.
평소에는 저장소 링크가 모두 숨겨져 있습니다 → [편집자 모드](#편집자-모드-저장소-링크). 자세한 형식은 [CONTENT_GUIDE.md](CONTENT_GUIDE.md) 참고.
잘못된 JSON을 저장하면 GitHub Actions가 실패 표시를 해주고, 앱은 마지막으로 정상이던 파일을 계속 사용합니다.

## 배포

GitHub → Settings → Pages → Source: **Deploy from a branch**, Branch: `main` / `/ (root)`.
몇 분 후 `https://<계정>.github.io/<저장소>/` 에서 접속할 수 있습니다.

### 편집자 모드 (저장소 링크)

앱 화면에는 **저장소 주소도, GitHub 계정도 나오지 않습니다.** ✏️ 편집 링크는 *편집자 모드*
에서만 나타나고, 이 모드는 **설정 맨 아래 버전 표시(`OPIc Coach v…`)를 7번 연속으로 누르면**
켜집니다. 켜고 끈 상태는 그 기기 브라우저(`localStorage`)에만 저장되므로, 앱을 받은 다른
사람의 화면에는 아무것도 보이지 않습니다.

편집 링크의 주소는 소스에 적어 두지 않고 **접속한 GitHub Pages 주소에서 그때그때 유추**합니다
(`kevin.github.io/foo` → `github.com/kevin/foo`). 그래서 `js/config.js` 에는 계정명이 없습니다.
로컬 서버(`localhost`)에서는 유추할 수 없으니 편집자 모드를 켜도 링크 대신 안내 문구가 나옵니다.

> ⚠️ 이건 **화면에서 감추는 것**이지 접근 차단이 아닙니다. 공개 저장소는 주소만 알면 누구나 볼 수
> 있고, GitHub Pages 주소(`<계정>.github.io`)에 이미 계정명이 들어 있습니다. 저장소 내용을
> 정말 비공개로 두려면 **Settings → General → Change visibility → Private** 로 바꾸세요
> (비공개 저장소에서 Pages 를 게시하려면 GitHub Pro 이상이 필요하고, 배포된 앱은 그대로 동작합니다).

## 채점 방식 안내

앱의 점수는 실제 OPIc 채점이 아니라 **학습 방향을 잡기 위한 추정치**입니다. 전사된 답변에서
발화량(30) · 구성/연결어(25) · 문법/시제(15) · 어휘 다양성(15) · 유창성(15) 을 계산해 0~100점으로 만들고,
63점 이상 IM3, 78점 이상 IH, 90점 이상 AL 로 매핑합니다. 발음 자체는 음성 인식 일치율로만 간접 평가합니다.

음성이 **하나도 인식되지 않으면 채점하지 않습니다.** 등급이나 항목 점수를 매기는 대신 실패 원인과
해결 방법을 보여 주고, 기록·모의고사 평균에서도 제외합니다 (0점으로 남아 추이를 망가뜨리지 않게).

- 채점 로직 테스트: `node tools/test-scoring.mjs` (의존성 없이 바로 실행)
- 인식 실패 화면 테스트: `node tools/test-stt-fail.mjs` (playwright 필요)

## 음성 인식이 안 될 때

설정(⚙️) → 음성 → **🩺 음성 인식 점검 (5초)** 을 누르면 원인을 바로 알려 줍니다. 흔한 원인:

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| "마이크 권한이 거부돼 있어요" | 브라우저/앱 마이크 권한 | 주소창 자물쇠 → 권한 → 마이크 허용. 홈 화면 앱은 폰 설정 → 앱 권한도 확인 |
| "인터넷 연결이 필요해요" | STT는 온라인 전용 | Wi-Fi·데이터 확인 (듣기·표현 학습은 오프라인에서도 됨) |
| "말소리가 잡히지 않았어요" | 마이크 거리·소음, 또는 녹음과 마이크 경합 | 가까이서 또박또박, 이어폰 마이크 사용. 계속 실패하면 설정에서 **답변 오디오 녹음**을 끄기 |
| 음성 인식 ❌ 표시 | 브라우저 미지원 | Android Chrome / iPhone Safari 사용 |

안드로이드에서는 녹음(MediaRecorder)이 마이크를 잡고 있으면 음성 인식이 막히는 기기가 있습니다.
그래서 설정에 **답변 오디오 녹음 켬/끔** 을 두었습니다. 끄면 다시 듣기는 못 하지만 인식률이 올라갑니다.
인식에 실패해도 답변을 **직접 입력해 채점**받을 수 있습니다.

## 시험 일정 데이터

OPIc은 고정된 시험일 목록이 없는 **상시시험**이라, 홈 D-day는 `data/exam-schedule.json`
의 휴무 규칙(일요일 + 공휴일)으로 **다음 응시 가능일**을 계산합니다. 접수 마감일도
같은 파일의 `registration.closesDaysBefore` 로 구합니다.

- 공휴일은 `.github/workflows/exam-schedule.yml` 이 매달 자동 갱신합니다.
  수동 실행은 `node tools/update-exam-schedule.mjs`.
- 임시공휴일처럼 API에 늦게 반영되는 날은 `holidays` 에 직접 추가해도 됩니다
  (자동 갱신 때 지워지지 않고 유지됩니다).
- `coverageUntil` 이 지나면 앱은 일요일만 제외해 계산하고 홈에 안내를 띄웁니다.
  워크플로도 이슈를 열어 알립니다.
- 날짜 계산 테스트: `node tools/test-exam.mjs`

접수 마감·좌석 정책은 앱 안내가 아니라 [공식 사이트](https://www.opic.or.kr)가 기준입니다.

## 자동 반복 재생 · 화면 유지

버튼을 매번 누르지 않고 듣고 → 따라 말하기를 반복할 수 있습니다.

- **▶ 자동 재생**: 주제 표현 · 주제 패턴 · 만능 패턴 목록 상단
- **카드 모드**: 카드를 열면 바로 재생. **⏸ 멈춤 / ▶ 다시 듣기** 로 직접 제어
- **섀도잉 ▶ 전체 듣기**: 문장마다 반복하며 처음부터 끝까지
- **🔁 계속 / 🔂 한 번**: 🔁 이면 **멈추기 전까지 계속 반복**합니다(기본값). 목록·섀도잉은
  끝까지 간 뒤 처음부터 다시, 카드 모드는 그 카드를 계속 읽습니다. 🔂 로 바꾸면 정해진
  반복 횟수만 읽고 멈춥니다.
- **반복 횟수**(1·2·3·5회)와 **간격**(0·0.8·1.5·2.5초), 🔁 설정은 화면끼리 공유되고 저장됩니다

멈추는 방법: 목록은 **⏸ 멈춤**, 카드 모드는 **⏸ 멈춤**(또는 🔊/🐢 를 직접 누르거나 다음 카드로
이동), 섀도잉은 **⏸ 멈춤**. 화면을 벗어나면 자동으로 멈춥니다.

재생·녹음·모의고사 중에는 [Screen Wake Lock](https://developer.mozilla.org/docs/Web/API/Screen_Wake_Lock_API)
으로 화면이 꺼지지 않습니다. Android Chrome 과 iOS Safari 16.4+ 에서 동작하며,
지원하지 않는 브라우저에서는 자동 재생만 되고 화면 유지는 안내가 표시되지 않습니다.

### 🌙 화면 어둡게 · 이어폰을 빼면 정지

폰의 음성 합성(speechSynthesis)은 **화면이 꺼지면 브라우저가 멈춥니다** (웹앱에서는 막을 수 없음).
그래서 재생 중에는 화면을 켜 둔 채(wake lock) **🌙 화면 어둡게** 로 화면 전체를 검게 덮어, 끈 것처럼 두고
계속 듣습니다 (`js/dim.js`). OLED 화면은 검은 부분이 거의 꺼진 것과 같습니다.

- 자동 재생 · 전체 듣기 · 카드 반복 중에 오른쪽 아래 **🌙 화면 어둡게** 버튼이 뜹니다. 덮개는 **두 번 탭**하면
  걷히고(주머니 속 스침 방지), 재생이 끝나면 저절로 걷힙니다. 안내 문구는 잔상 방지를 위해 가끔 자리를 옮깁니다.
- 설정 → 음성 → **재생 중 자동으로 화면 어둡게**: 끔 · 15초 · 30초 · 1분 동안 화면을 만지지 않으면 저절로 어두워집니다.
- 전원 버튼으로 화면을 끄거나 다른 앱으로 가면 재생을 멈추고 🌙 를 안내합니다.
- 이어폰(유선·블루투스)이 빠지면 멈춥니다: 재생하는 동안 거의 들리지 않는 소리를 `<audio>` 로 함께 틀어 두고,
  안드로이드가 이를 일시정지(becoming noisy)하면 재생을 멈춥니다 (`js/background.js`). 통화 등 다른 앱이 소리를
  가져가도 멈춥니다. 설정 → 음성 → **이어폰을 빼면 멈춤** 으로 켜고 끕니다.

테스트: `tools/test-background.mjs`.

가로 화면은 `manifest.webmanifest` 의 `orientation: "any"` 와
`@media (orientation: landscape)` 규칙으로 지원합니다.

UI 테스트(자동 재생·화면 유지·가로 화면)는 `tools/test-ui.mjs` 에 있습니다.
저장소를 의존성 없이 유지하려고 CI 에는 넣지 않았으니, 돌려 보려면 파일 맨 위 안내를 따르세요.
